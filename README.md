# SplitNest (made-up demo app)

SplitNest is a made-up rent-splitting app for roommates in San Francisco, built only for a YouTube demo of Google Stitch Loop. It is not a real service. Every name, email, amount and card number in it is invented.

It has problems planted on purpose so Stitch Loop has something to find:
- the signup form loses most people
- the activity page is slow
- a few security holes

`context/` holds made-up user feedback and made-up social media numbers for the demo.
